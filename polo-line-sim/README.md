# polo-line-sim

폴로 셔츠를 도시형 마이크로팩토리에서 로트 사이즈 1로 생산할 때, **어떤 신체 치수를 재야 하고 · 어떤 기계가 필요하며 · 어떤 산업 수치가 나오는지**를 터미널에서 계산해 보여주는 도구입니다.

근거 문서는 Maß-DPP 사업 계획서(`Anlage_zum_Antrag_ITA.pdf`, ITA × ColorDigital GmbH)입니다. 계획서는 **드레스 셔츠** 기준이므로, 이 도구는 그 수치를 **폴로(니트)** 기준으로 분해해 다시 계산합니다.

## 실행

파이썬 3.10 이상, 표준 라이브러리만 사용합니다. 설치할 것이 없습니다.

```bash
python run.py
```

| 명령 | 설명 |
| --- | --- |
| `python run.py` | 전체 보고 — 측정 · 설비 · 시뮬레이션 |
| `python run.py --section simulation` | 시뮬레이션만 |
| `python run.py --live` | 폴로 1벌이 라인을 통과하는 과정을 재생 |
| `python run.py --live --dpp` | 재생 후 DPP JSON 전문 출력 |
| `python run.py --embroidery --print` | 선택 모듈(자수 · 프린트)을 켜고 재계산 |
| `python run.py --runs 20000 -v` | 표본을 늘리고 가정값까지 표시 |
| `python -m unittest` | 스모크 테스트 36개 |

`--no-color`로 ANSI 색상을 끌 수 있고, `--live --delay 0`이면 애니메이션 없이 한 번에 출력합니다.

터미널 출력은 영어입니다 — ITA 동료와 그대로 공유할 수 있도록 했습니다. 코드 주석과 이 문서는 한국어로 남겨 두었습니다.

## 무엇을 계산하는가

**1. 3D 스캔 측정 항목** — 폴로 패턴 제도에 필요한 치수 12개를 `body-measure/measurement-spec.v1.yaml`(spec_version 4)과 대조합니다. 7개는 이미 정의되어 있고, 5개(밑단둘레 · 소매단 둘레 · 암홀 깊이 · 어깨 경사각 · 앞품/뒤품)는 폴로 때문에 새로 필요합니다. 명세에 없는 항목은 조용히 빠지지 않고 항상 `not in the spec`으로 표시됩니다.

**2. 설비 구성** — 계획서 표 3의 설비(Zünd S3 커터, Pfaff 본봉, Veit SF 27 피니셔, 카메라 QC, 선택 ZSK 자수 / Kornit 프린터)와, 니트 봉제 때문에 추가되는 설비(오버로크, 커버스티치, 립 공급, 단추기), 그리고 공정 인프라(이송·센서·AI 어시스턴트·DPP 라벨)를 정리합니다.

**3. 산업 수치 시뮬레이션** — 몬테카를로로 공정 시간 분포를 내고, 원가·라인 확장·데이터 발생량을 계산합니다.

## 주요 결과

기본 구성(선택 모듈 없음, 9개 모듈, 공칭 34.5분) 기준입니다.

| 항목 | 값 | 계획서 목표 |
| --- | --- | --- |
| 평균 흐름시간 | 34.9분 (P95 38.7) | 36분 미만 |
| 36분 목표 달성률 | 76.9% | — |
| 1벌 원가 (작업자 전담) | 21.02 € | 13~15 € |
| 1벌 원가 (병렬 모듈) | 17.76 € | 13~15 € |
| 벌당 에너지 / CO₂ | 0.907 kWh / 344 g | DPP 자동 산출 대상 |
| 센서 포인트 | 벌당 약 20,900개 → DPP 15 kB | 15 kB/제품 |

### 원가 모델이 두 개인 이유

작업자가 셔츠 1벌을 처음부터 끝까지 전담하면 인건비가 흐름시간 34.9분 전체에 붙어 **21.02 €**가 됩니다. 모듈을 병렬로 두면 기계가 도는 동안(재단·피니싱·QC) 작업자는 다른 셔츠를 잡을 수 있으므로, 1벌에 실제로 붙는 시간은 **26.0분**이고 원가는 **17.76 €**로 내려갑니다.

그래도 목표 15 €에는 미치지 못합니다. 15 €를 맞추려면 실투입이 **18.5분 이하**여야 하므로 **7.5분**을 더 줄여야 합니다. 남은 실투입 26분 중 21분이 재봉(오버로크·본봉·커버스티치·립 부착)이고 이 구간은 작업자가 100% 붙어 있으므로, **재봉 실투입을 약 36% 줄이지 못하면 목표 원가에 도달하지 못합니다.** 계획서의 AI 어시스턴트가 실제로 해내야 하는 일이 이것입니다.

### 라인 확장

각 설비를 1대씩만 둔 선형 구성의 최대 생산율은 **6.4벌/시간**입니다(가장 느린 오버로크 8분이 결정). 계획서가 말하는 시간당 20벌에 도달하려면:

| 목표 생산율 | takt | 총 설비 | 인원 | 복제 대상 |
| --- | --- | --- | --- | --- |
| 2벌/h | 25.5분 | 9대 | 2명 | 복제 불필요 |
| 5벌/h | 10.2분 | 9대 | 3명 | 복제 불필요 |
| 10벌/h | 5.1분 | 10대 | 6명 | Overlock×2 |
| 20벌/h | 2.5분 | 17대 | 11명 | Zünd×2 · Overlock×4 · Pfaff×2 · Coverstitch×2 · Flat-knit×2 · Veit×2 |

생산율이 올라가면 병목이 오버로크(8분)에서 본봉·피니싱(각 5분)으로 옮겨갑니다. 즉 **증기 프레스도 재봉기와 함께 복제해야** 합니다.

## 근거와 가정의 구분

계획서에서 온 값과 이 도구의 가정을 섞지 않습니다. 모든 상수는 [`polo_line/spec.py`](polo_line/spec.py)에 모여 있고 주석으로 출처가 붙어 있습니다. 2026-08-26에 독일어 원문(`Anlage_zum_Antrag_ITA.pdf`)과 전수 대조했습니다.

> **쪽 번호 주의** — 이 문서의 쪽 인용은 계획서 자체의 `Seite N von 55` 기준입니다. PDF 뷰어 쪽 번호는 여기에 4를 더한 값입니다(Seite 37 = PDF 41쪽). 독일 측과 문서를 주고받을 때는 Seite 를 쓰십시오.

**계획서 원문 근거** (인용 가능)

| 값 | 위치 | 원문 |
| --- | --- | --- |
| 36분 미만 · 13~15 € | Seite 4 | „Maßhemden in Losgröße 1 in <36 Minuten zu Produktionskosten von 13 bis 15 Euro" |
| 벤치마크 37분 | Seite 4 · 28 | 동남아 대량생산 „>37 Minuten" |
| 표 3 설비군 | Seite 37 | Zünd S3 / Pfaff / Veit SF 27 / Kamerasystem / ZSK / Epson·Kornit |
| 실시간 수집 <1초 | Seite 37 · 38 | „in Echtzeit (< 1 s)" |
| 수작업 100분 미만 | Seite 37 | 1단계 중간 목표 |
| 공정 흐름 · 라인 출발점 | Seite 38 | „Ausgangspunkt … individuellen Angaben des Endverbrauchers" |
| AI 이상 변수 식별 <2초 | Seite 39 · 48 | 개발 목표 ITA 2 / 마일스톤 MS 7 |
| DPP 15 kB · 연 6.25 TB | Seite 31 | 5,000제품 × 50,000사업장 기준 |
| 시간당 2~20벌 확장 | Seite 48 | „<2 Hemden pro Stunde … >20 Hemden pro Stunde" |
| 표 4 모듈 처리 시간 | Seite 49 | 커터 3 · 재봉 25 · 다림질 6 · 포장 2 |

**계획서에 없는 것** (도출 또는 가정)

- **신체 치수 12종** — 계획서에는 치수 목록이 없습니다. Seite 38이 „예: 사이즈, 색상, 재단, 원단 선택"이라 적을 뿐 사이즈를 분해하지 않고, 원문 전수 검색에도 `Körpermaß`·`Brustumfang` 류는 나오지 않습니다. 이 목록은 의류 패턴 실무와 ISO 8559-1에서 도출한 것입니다.
- **폴로 자체** — 원문에 `Polo`는 0건이고 `Hemd`가 44건입니다. 계획서의 대상은 일관되게 드레스 셔츠이며, 폴로 적용은 이 도구의 확장입니다.
- **오버로크 · 커버스티치 · 립 공급 · 단추기 · DPP 라벨 유닛** — 표 3의 원문은 „Spezialisierte Pfaff **Nähmaschinen**"(복수)이고 공정명도 „Nähen"뿐이라 스티치 종류를 특정하지 않습니다. 단추와 DPP 라벨링은 공정 기술(Seite 25 · 38)에만 나오고 표 3에 기계가 없습니다. 즉 이 설비들은 계획서가 **배제한** 것이 아니라 **명시하지 않은** 것입니다 — 도구는 이들을 `unspecified`으로 표시합니다. 니트 봉제에 필요하다는 근거는 봉제 실무에서 옵니다.
- **모듈 시간 재분해** — 재봉 25분 → 오버로크 8 + 본봉 5 + 커버스티치 4 + 립 부착 4, 니트 피니싱 5분, 품질 검사 1.5분, 라벨링 2분.
- **수치 모델 전부** — 모듈별 정격 전력, 작업자 점유율, 임금 22 €/h, 전기 0.25 €/kWh, 자재 6.50 €, 감가 1.50 €, 라인 상시 부하 0.3 kW, 실가동률 85%, 변동계수 12%, 재작업률 6%, 센서 판독값과 채널 수.

`-v` 옵션을 붙이면 가정값 일람이 함께 출력됩니다.

### 표 4에 대한 관찰

계획서 표 4의 네 모듈을 더하면 3 + 25 + 6 + 2 = **정확히 36분**으로, 목표 상한과 같습니다. 계획서 자체 추정치에 여유가 없다는 뜻이고, 품질 검사와 DPP 라벨링은 공정 흐름(Seite 38)에는 나오지만 표 4에 시간이 잡혀 있지 않습니다. 이 도구는 두 모듈에 시간을 부여하고도 34.5분에 들어가므로, 계획서 자체 수치보다 오히려 여유가 있습니다.

## 구조

```
polo-line-sim/
├── run.py                    진입점 (argparse)
├── test_polo_line.py         스모크 테스트 36개
└── polo_line/
    ├── spec.py               설비·측정·원가 상수 — 근거/가정 표시
    ├── measurements.py       1. 3D 측정 항목 + 명세 대조
    ├── machines.py           2. 설비 구성
    ├── simulate.py           3. 몬테카를로 · 원가 · 라인 밸런싱
    ├── live.py               라인 통과 재생 + DPP 조립
    └── term.py               터미널 렌더링 (동아시아 문자 폭 계산 포함)
```

한글은 터미널에서 두 칸을 차지하므로 `term.dwidth()`가 표 정렬을 담당합니다. `len()`으로 폭을 재면 표가 어긋납니다.
